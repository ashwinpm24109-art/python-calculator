# Python Calculator (GUI)

A simple calculator with a graphical interface, built with Python and Tkinter.

## Features

- Supports `+`, `-`, `*`, `/`, powers (`**`), negative numbers, and parentheses
- Button and keyboard input
- Enter for `=`, Backspace to delete, Escape to clear
- Shows an error for division by zero or an invalid expression
- Evaluates expressions with a safe parser instead of `eval`

## Requirements

- Python 3.8 or newer. Tkinter comes with the standard Windows installer.

## How to run

```bash
python calculator.py
```

On Windows, if `python` isn't recognized, try `py calculator.py`.
